# 🗣 MellstroyMemesTranslate for Vencord

**MellstroyMemesTranslate** — единый мемный переводчик интерфейса Discord и сообщений для [Vencord](https://github.com) с 4 диалектами, интерактивной панелью выбора в стиле *CustomThemes* и окном выбора стиля прямо перед отправкой сообщения.

---

## ✨ Возможности

- **4 мемных диалекта в одном плагине:**
  1. **Муринский** — каноничные замены (`я → ч`, `друг → друн`, `сын → сыр`) + фирменное окончание `-ость` без затрагивания глаголов.
  2. **Село Молочное** — тематический словарь (`павук`, `трамвай`, `Паучья яма`, `молочко`, `Crna dvojka`) + окончания `-очность / -ность`.
  3. **Мытищинский** — подмосковный вайб (`Перловка`, `Яуза`, `электричка Спутник`, `Ярославка`, `Красный Кит`) + окончания `-ищи / -инск`.
  4. **Меллстройский (Всеобщий)** — стримерский сленг (`бабки`, `занос`, `братва`, `чатик`, `подрубка`, `казик`).
- **Визуальная панель настроек:** кликабельные карточки диалектов с акцентными бейджами и чипы режимов отправки.
- **Окно выбора при отправке (`1–4`):** при нажатии `Enter` показывает предпросмотр сообщения на всех 4 языках (выбор кнопкой или клавишами `1`, `2`, `3`, `4`, а `0` отправляет чистый оригинал).
- **Откат по ПКМ:** правый клик по любому сообщению → **«Убрать мемный перевод»**, чтобы прочитать оригинал.

## 📦 Установка

### Вариант А: Как встроенный `userplugin` (исходники Vencord)
1. Скопируйте папку `mellstroyMemesTranslate` (с файлом `index.tsx`) в директорию:
   ```text
   src/userplugins/mellstroyMemesTranslate/
   ```
2. Соберите и заинжектите Vencord:
   ```bash
   pnpm build
   pnpm inject
   ```
3. Обновите Discord (`Ctrl + R`) и включите **MellstroyMemesTranslate** в **Настройки → Vencord → Plugins**.

### Вариант Б: Через `ExternalPluginsLoader` (без сборки)
1. Поместите готовый файл `MellstroyMemesTranslate.js` в папку `AppData\Roaming\Vencord\plugins`.
2. Откройте **Настройки → Vencord → External Plugins** и нажмите **Load missing Plugins**.
3. Настройка и выбор диалектов доступны по кнопке **🌐 Диалект** или горячей клавише **`Alt + T`**, а откат сообщения — по **`Alt + ПКМ`**.
